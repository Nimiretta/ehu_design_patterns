# Генератор тестовых данных JSON/XML

Позволяет интерактивно собирать структуры данных и экспортировать их в формате JSON или XML.

## Паттерны:

- Composite (структура дерева),
- Builder (JSON/XML генерация),
- Strategy (генерация значений),
- Observer (live preview),
- Facade (экспорт),
- Singleton (AppConfig).
